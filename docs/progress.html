Blighted New World Emulator: Progress

Deadline: the retail servers shut down on 2027-01-31. After that day, nobody can record a new retail capture. Systems with no retail capture must be recorded before then.
How to read the checks. Each feature is a list of checks: things that must work as on retail. Each check has its own proof. A check is proven only when it was seen to work with the real client (Live) or with test bots (Bots). "3 of 8 checks proven" counts those. Automatic tests and code alone do not make a check proven, and no percent is shown: we cannot measure a share of retail. Tools that the client does not use (setup, game data, capture decoders, admin tools) are proven by their own runs.
