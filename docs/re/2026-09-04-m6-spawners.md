## Two lists, not one

**Observed.** The world-format note, section 5.5, counts the vitals section of open-world `region.metadata`: 115,937 records. Each record has a vitals id, a category id, a level, and a world position.

**Observed.** The same note, section 5.3, counts open-world capitals whose slice path is a `pointspawner_*.dynamicslice`: 36,471. A capital has its own world position, rotation, and slice asset id.

**Inferred.** These are not the same list. 115,937 is not 36,471. A server that spawns once from the vitals section and again from every point-spawner capital will spawn some creatures twice if any capital sits on a vitals record. A server that uses only one list will miss the creatures that exist only on the other list.

**Observed.** The two lists do not share an id field. The vitals section has 115,937 records. Each record's id is `vitalsId`, a crc32. A point-spawner capital has 36,471 records in the open world. Each capital's id is a GUID string, and `sliceAssetId` is a GUID plus a sub-id. A crc32 word and a GUID are different id spaces. Compared: 115,937 crc32 vitals ids against 36,471 GUID capital ids. The overlap on id is 0, because no field has the same form. A spatial join of the two position sets was not run. The positions are not copied here.
